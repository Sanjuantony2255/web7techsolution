## 🌐 GitHub Pages Deployment Guide

This project has **zero build dependencies** and is 100% static:

1. Create a repository on GitHub (e.g. `web7techsolutions`).
2. Upload all files from this directory (`index.html`, `assets/`, `README.md`).
3. In GitHub, go to **Settings** > **Pages**.
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **`main`** / **`/ (root)`**
5. Click **Save**. Your website will be live in 60 seconds at:
   ```
   https://<your-username>.github.io/web7techsolutions/
   ```
